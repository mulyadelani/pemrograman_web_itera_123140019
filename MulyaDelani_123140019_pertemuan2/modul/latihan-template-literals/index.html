MODUL LATIHAN · JAVASCRIPT ES6+

Template Literals

Bandingkan cara lama merangkai string dengan cara modern yang lebih rapi dan mudah dibaca.

Sintaks dasar

Concatenation

const greeting = "Halo, " + name + "!";

Menggabungkan potongan teks dan variabel dengan operator +.

Template literal

const greeting = `Halo, ${name}!`;

Gunakan backtick dan sisipkan variabel atau ekspresi dengan ${...}.

Latihan mandiri

  3. Ubah nama dan umur pada demoTemplateLiterals(), lalu bandingkan hasil concatenation dan template literal.

  5. Ubah ekspresi perhitungan tahun lahir dan jalankan demo kembali.
