# Latihan Template Literals

Latihan interaktif JavaScript ES6+ untuk membandingkan concatenation dengan template literals. Tombol **Run Demo** menampilkan tiga demo:

1. `let` dan `const`, termasuk perbedaan scope dan objek `const`.
2. Arrow functions dan fungsi reguler.
3. Template literals untuk interpolasi variabel, string HTML multi-baris, dan ekspresi menghitung perkiraan tahun lahir.

## Menjalankan

Buka `index.html` di folder ini langsung di browser, atau gunakan Live Server di VS Code. Demo ini juga sudah disematkan pada halaman utama Bloom Study.

Klik **Run Demo** untuk melihat hasil. Tantangan mandiri tersedia di bagian bawah halaman.
